# Zinogre (personal build) — NeoForge 1.21.1, needs Shadered

A Zinogre mob (spawn egg in the Spawn Eggs tab) drawn with Shadered's model renderer, with idle, walk/run and a
lunging melee attack.

**This branch holds code only.** The model (`assets/zinogre/models/complex/zinogre.glb`) is a personal conversion of
a Monster Hunter World asset (Capcom) and is deliberately not in this repository: it is added to the jar locally and
must not be published. Without it the mob is invisible.
